# films

Web copies of Steven Kauwe's music videos, served by GitHub Pages at https://stevenkauwe.github.io/films/ and
played from the gallery on https://stevenkauwe.github.io/.

Per film: `<slug>.mp4` (H.264 1080p, about 2.5 Mbit/s, AAC, faststart), `<slug>.webp` (a 5 s preview loop) and
`<slug>-poster.webp` (a still). The films are made in a separate studio repo and encoded with its
`tools/web-encode.sh`.

This repo is always a single commit: when the lineup changes, it is replaced wholesale rather than grown.
